## Abstract (skeleton)
Task-oriented dialogue increasingly uses small language models (SLMs) that emit
structured output (intent + slots) via autoregressive generation. We show that
for *closed-set* intent detection and slot filling this is both slow and brittle.
We present a recipe that converts a generative SLM into a **discriminative
single-pass** model: (1) a frozen-probe layer sweep selects a pruned backbone
depth, (2) a linear intent head and a CRF BIO slot head replace token-by-token
generation, and (3) intent-conditioned rules recover non-span ("implicit") slots.
Across ATIS, SNIPS, MASSIVE, CLINC150, and BANKING77 our probe-pruned
discriminative model runs at a fraction of the generative model's CPU latency
(e.g. ~70x faster on ATIS: 5.1ms vs 359ms), matches or improves intent
accuracy, and eliminates a generative parse-failure rate of up to 46.7% on
complex slot schemas (0% by construction). A 15-second linear probe correctly
selects a 4x-shallower backbone depth a priori on all five datasets. We further
contribute a negative-results study of common CPU inference optimizations and
their failure root causes.

## 1. Introduction
- Trend: generative SLMs for structured NLU. Cost: autoregressive decode latency,
  and non-zero rate of malformed structured output.
- Claim: closed-set intent + slot filling does not need generation.
- Contributions bullet list (see PROPOSAL.md).

## 3. Method
### 3.1 Problem setup
- Closed intent set; slot set with BIO tagging; single-pass discriminative output.
### 3.2 Probe-guided depth selection
- Freeze base SLM; train linear probe on hidden states at layers {L/4, L/2, 3L/4, L}.
- Pick smallest depth within ε of full-depth probe accuracy → prune to that depth.
### 3.3 Discriminative heads
- Intent: `Linear(d_model → |intents|)`, argmax.
- Slots: `Linear(d_model → |BIO tags|) + CRF`, Viterbi decode.
- Joint loss: `L = L_intent + λ · L_slot(CRF-NLL)`, with slot-token upweighting.
### 3.4 Implicit-slot recovery (summary; full treatment in Paper 2)
- Intent-conditioned deterministic rules for non-span slots; precision-first.
### 3.5 Why generation removal is a reliability win
- Discriminative output is structurally valid by construction → 0% parse failure.

### 5.1 Main comparison — generative vs encoder vs ours (ATIS)
| Model | Intent Acc | Slot F1 | Parse-fail | Lat P50 (CPU) |
|---|---:|---:|---:|---:|
| Generative SLM, gpt2 full-depth (autoregressive) | 48.3% | 44.6% | **46.7%** | 359 ms |
| Encoder discriminative (DistilBERT, 6L, bidirectional) | 98.98% | **95.1%** | 0% | 7.0 ms |
| **Ours: probe-pruned discriminative (gpt2 depth-3)** | **97.95%** | 91.0% | **0%** | **5.1 ms** |

Headline: vs the generative baseline the pruned discriminative model is **~70x
faster**, **+49.6pt intent**, and eliminates a **46.7% parse-failure rate**. vs a
purpose-built bidirectional encoder it is faster and matches intent accuracy,
trailing on slot F1 (causal-attention cost, see 5.3 CRF ablation).

### 5.2 Probe layer sweep (frozen gpt2, linear probe on intent)
| Depth | ATIS probe acc | Recommended? |
|---:|---:|---|
| 3 (L/4) | 95.00% | **<- pick (within eps=0.02 of best)** |
| 6 (L/2) | 95.38% | |
| 9 (3L/4) | 95.25% | |
| 12 (full) | 96.00% | |

**All 5 datasets independently recommend depth=3.** Empirical Gate-B validation
(full fine-tune at depth 3 vs 12) confirms the probe: depth-3 matches or is
within ~1pt of full-depth intent accuracy on ATIS/SNIPS, with a real but still
favorable 2.4-3.0pt cost on the 100+-class fine-grained intent taxonomies
(CLINC150, BANKING77) -- an honest finding: **depth requirement scales with
intent-set granularity.** Every depth-3 config is ~4x faster than depth-12.

### 5.3 Ablations
- **CRF vs softmax slot head:** Table 3 in aggregated results (depths-3, ATIS/
  SNIPS/MASSIVE). Hypothesis: CRF narrows the slot-F1 gap vs the bidirectional

- **Depth Pareto (quality/latency):** Table 2 -- ATIS full 4-depth curve
  (3/6/9/12), 2-point {3,12} on the other four; latency scales ~linearly with

- **Seed variance (>=3 seeds):** Table 4, mean +/- std over seeds {42,1,2}.
- Slot-loss weight lambda: fixed at 2.0 here; sweep is a stretch item.

### 5.4 Reliability — parse-failure rate (generative vs discriminative)
| Dataset (slot schema) | Generative parse-fail | Discriminative |
|---|---:|---:|
| ATIS (101 tag types) | 46.7% | **0% (by construction)** |
| SNIPS (72 tag types) | 3.3% | **0%** |
| CLINC150 (intent-only) | 0.0% | **0%** |

Parse-failure rate AND generative latency both scale with output-structure
complexity (359 -> 243 -> 83 ms across the three); the discriminative model is
structurally immune to this axis (flat ~5-7 ms, always-valid output).

## 6. Negative Results: CPU Inference Optimizations That Didn't Pay Off
For each, report result + root cause on public models:
- Naive dynamic INT8 (activation outliers).
- Rotation-based INT8 (QuaRot/Hadamard) — accuracy recovered, speed needs fused
  kernels.
- ONNX / graph export for decoder SLMs (dynamic KV cache / dynamic shapes).
- Graph compilation (codegen edge cases on decoder architectures).
- Vendor CPU extensions (instruction-set dependence).
- Takeaway: for shallow closed-set tasks on commodity CPUs, depth pruning +
  discriminative heads dominates.

## 7. Discussion & Limitations
- Closed-set assumption; open-set / novel-intent detection out of scope.
- Generation still needed for free-form generation tasks.
- Implicit-slot rules are dataset/intent specific (see Paper 2).

## 8. Conclusion
- Restate: generate less, classify more.
